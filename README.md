🔗 **[Dial into the Live Experience →]https://jiya17batra.github.io/Nokya/

---

## 🌸 About The Concept

I wanted to build something that feels less like scrolling through another generic developer résumé and more like discovering a person through an unexpected digital artifact. 

So instead of standard rows and cards, I turned my portfolio into **No-Kya?** — a nostalgic, interactive Y2K-inspired retro mobile phone where every key press, sound effect, and pixelated screen transition reveals a different part of my journey.

There are projects I’ve built, tools I wield, creative motion archives, career milestones, and even a working retro photo booth tucked inside the screen. 

Don't just skim through it — pick up the keypad, start dialing, and explore. You might find something you weren't expecting. 📟

---

## ✨ Features

- **Tactile 12-Key Physical Keypad:** Dial keys `0` through `9`, `*`, and `#` on your physical keyboard or tap the buttons to navigate sections.
- **Classic Monochrome LCD Interface:** Authentic dot-matrix aesthetic, scanline textures, and dynamic status bars with animated tickers.
- **8-Bit Web Audio Synthesizer:** Real-time synthesized keypress chirps and boot chimes using the native Web Audio API (no heavy MP3s).
- **Interactive Retro Photo Booth:** Live webcam integration with instant retro grayscale Polaroid snapshot rendering.
- **Directional D-Pad Navigation:** Scroll seamlessly through sub-items across projects, career timelines, and skillsets.

## 🛠️ Built With

- **HTML5 & Vanilla JavaScript:** Lightweight logic, state routing, and Web Audio API synthesis
- **Tailwind CSS & Custom CSS:** Custom gradients, authentic inset shadows, and LCD screen scanline effects
- **Google Fonts:** Plus Jakarta Sans & Caveat for handwritten Polaroid notes
- **MediaDevices API:** Camera booth feed and canvas snapshot generation

## 🚀 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/jiya17batra/nokia-portfolio.git
   cd nokia-portfolio
   ```

2. Open `index.html` directly in your browser or run a simple local server:
   ```bash
   npx serve .
   ```

3. Ensure you have `img.png` in the root folder for the retro boot animation.
